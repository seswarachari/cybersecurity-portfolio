## 🛡️ Overview

This portfolio showcases hands-on security operations, detection engineering architectures, incident triage workflows, and verified industry credentials:

* **3D Perspective Hologram**: Interactive tactical portrait card with live IST clock, telemetry brackets, and operational indicators.
* **Interactive SOC Triage Simulator**: Step-by-step walkthroughs of 4 real-world incidents (Windows LOLBins, AgentTesla Malware Detonation, Phishing Triage, and C2 Beacon Detection).
* **Selected Work & Open Architecture**: 7 security case studies with pipeline dataflow diagrams, MITRE ATT&CK mappings, and production-ready detection rules in **Wazuh XML**, **Microsoft Sentinel KQL**, and **Sigma/Python**.
* **Verified Credentials Ledger**: 8 verified global certifications (CompTIA CSAP, CySA+, Security+, Stellar Cyber XDR, LetsDefend, Cisco, Google, ISC2) with direct artifact viewing and Credly links.
* **Customization Studio**: In-browser profile customizer to update portraits, edit copy, and add new projects or certifications.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/seswarachari/cybersecurity-portfolio.git

# Navigate into the project directory
cd cybersecurity-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will start on `http://localhost:3000/`.

### Build for Production

```bash
# Create optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

### Type Checking & Tests

```bash
# Verify TypeScript types
npm run lint

# Run unit tests
npx tsx src/utils/portfolioLogic.test.ts
```
